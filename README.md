Night Harbor is a round-based tactical FPS in three.js: 5v5 rounds on the Blackwater Docks container port, a Spark Charge to plant at site A or B and defuse, an economy and buy menu between rounds, and bots that hold angles, rotate on the plant and investigate gunshots. Single-player against bots, static files, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
